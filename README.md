
# AI Resume Analyzer

A web application that analyzes resumes and compares candidate skills against a job description.

## Features
- Upload PDF and DOCX resumes
- Extract resume text
- Detect technical skills
- Compare skills with job requirements
- Calculate a skill match score
- Identify matched and missing skills
- Provide resume improvement suggestions

## Tech Stack
- Python
- Flask
- PyMuPDF
- python-docx
- HTML
- CSS

## Installation

1. Clone this repository.
2. Install dependencies:

   `python -m pip install -r requirements.txt`

3. Run the application:

   `python app.py`

4. Open `http://127.0.0.1:5000` in your browser.

## Disclaimer
The match score is a basic keyword-based estimate, not a hiring decision or a guarantee of job suitability.
